# 📊 Amazon Sales Analysis Dashboard (Power BI)

## 📌 Project Overview

The Amazon Sales Analysis Dashboard is an interactive Power BI project developed to analyze sales performance and business trends using Amazon sales data. The dashboard provides meaningful insights into sales, product categories, courier status, fulfillment methods, and product sizes to support data-driven decision-making.

---

## 🎯 Objectives

- Analyze overall sales performance.
- Identify the top-performing product categories.
- Monitor courier and delivery status.
- Compare fulfillment methods.
- Understand product size distribution.
- Build an interactive dashboard for business insights.

---

## 📂 Dataset

The dataset contains Amazon sales records with information such as:

- Order Date
- Product Category
- Sales Amount
- Courier Status
- Fulfillment Method
- Delivery Partner
- Product Size

- 📊 Fulfillment Analysis

## 📊 Key Insights

- Identified the highest-performing product categories.
- Compared shipped, cancelled, and unshipped orders.
- Analyzed fulfillment methods used for deliveries.
